# Источники свежих WB-цен: границы доступа и безопасный следующий шаг

Проверка: 2026-10-11. Только исследование и собственные локальные артефакты
PR10. Production, D1, Telegram, Cron, AI, PR8/PR9 не вызывались и не изменялись.
Новых токенов, услуг, прокси или интеграций не создавали.

## Что действительно подтверждено

`docs/shadow-20261011/price-check.json` содержит один уже выполненный запрос
к `search.wb.ru/exactmatch/ru/common/v9/search`, HTTP **403**,
`confirmedProducts=[]`, `status=UNAVAILABLE`. Он не повторялся в этом аудите.
Отдельный прежний receipt в `report.json` также фиксирует 403 от
`card.wb.ru/cards/v4/detail`, но без точного времени.

Это доказывает отказ конкретного пути из конкретной проверенной среды, а не
причину отказа. Сохранённый receipt не содержит ответа защиты или серверного
request ID: блокировка IP, отсутствующий разрешённый доступ, правила защиты,
контекст запроса и изменение endpoint **не различены**. Нельзя объявлять
«GitHub/Cloudflare заблокирован навсегда» или «достаточно заменить headers».
Текущее production-состояние этим локальным тестом не исследовалось.

Фото/`card.json` на CDN подтверждают изображение, идентичность и метаданные.
Успешный ответ CDN не подтверждает сегодняшнюю цену, наличие размера или
доставку. Старый снимок не становится свежим от загрузки новой фотографии.
`<=100 / <=200 / <=300 ₽` сейчас дают **0 подтверждённых свежих предложений**;
историческая карточка может оставаться в фотогалерее, но не в publishable-очереди.

## Официальный WB API — доступ магазина, не поиск всего retail-каталога

Официальная документация описывает доступ к данным магазина продавца через
выбранные категории и уровень Read Only. Персональный токен предназначен для
собственных программ, включая собственную арендованную инфраструктуру;
передача стороннему сервису требует подходящего официального типа доступа.
Сервисный токен связан с определённым сервисом. Это не разрешение читать
произвольные магазины или превращать seller API в публичный retail-search.
Для этого проекта токен другого продавца без его полномочий не подходит.
[Авторизация WB API](https://dev.wildberries.ru/openapi/api-information),
[система авторизации, обновление 06.04.2026](https://dev.wildberries.ru/knowledge-base/articles/019d49a1-0d73-71e9-be3e-b2c44567470c).

Документированные инструменты своего/разрешённого магазина:

| Данные | Метод / категория | Ограничение смысла |
|---|---|---|
| Карточки, фото, характеристики | `POST /content/v2/get/cards/list`, Content | Ассортимент разрешённого продавца, не общерыночный поиск |
| Цены по nmId | `POST /api/v2/list/goods/filter`, Prices and Discounts | Цена/скидки продавца, валюта, размеры и клубная цена; не доказательство цены checkout любого покупателя |
| Цены всех товаров магазина | `GET /api/v2/list/goods/filter` | Пагинация; опубликованное ограничение страницы до 1000 |
| Остатки склада продавца | `POST /api/v3/stocks/{warehouseId}`, Marketplace | Разрешённый склад/SKU; не обещание доставки в произвольный регион |

Лимиты задаются для конкретных методов, категорий и типов токена. Они не
универсальны: перед интеграцией проверить актуальную таблицу нужного метода.
Опубликованный burst не является рекомендацией создавать всплески в сборщике.
[Методы работы с товарами](https://dev.wildberries.ru/openapi/work-with-products).
WB отдельно менял лимиты по типам токенов с 30.03.2026; перед интеграцией нужны
актуальные ограничения конкретного доступа и обработка rate-limit headers.
[Изменение лимитов](https://dev.wildberries.ru/news/281).

`finishedPrice`/`spp` в отчётах заказов — сведения о состоявшихся заказах
продавца, а не котировка любого nmId сейчас. Документация предупреждает о
задержанном заполнении некоторых цен. Старый
`GET /api/v1/supplier/stocks` помечен deprecated: новую интеграцию на него
не строить. [Официальные отчёты](https://dev.wildberries.ru/en/openapi/reports).

В проверенных официальных материалах не найден документированный свободный
consumer API, обещающий весь ассортимент, сегодняшнюю покупательскую цену,
остаток и пригодность для публичного канала. Это результат ограниченного
исследования, не доказательство отсутствия любых закрытых партнёрских программ.

## Что можно рассматривать без обхода защиты

| Вариант | Условия допуска | Чего не обещать |
|---|---|---|
| API собственного магазина | Владелец магазина, подходящий тип доступа, Read Only нужных категорий | Доступ к чужим товарам и универсальную retail-цену |
| Feed от согласившегося продавца | Проверенные полномочия/условия распространения, договорённый JSON/CSV, источник и время наблюдения | Что лицензия продавца автоматически разрешает весь контент WB |
| Официальный партнёрский feed | Явное предоставление доступа WB/правообладателем, документированные поля, лимиты, цена и права использования | Что такой feed уже существует для нас, бесплатен или не требует согласования |
| Обычная карточка/браузер | Только разрешённый доступ без обхода; фиксированные вариант, регион и условия оплаты | Что браузер гарантированно снимет 403 или станет стабильным бесплатным сервером |
| Старый локальный резерв | Историческое исследование/фото; перед публикацией отдельная свежая проверка | Свежесть, наличие, новые найденные товары |

Тестовый токен WB/песочница не подтверждают реальные предложения:
они предназначены для изолированных тестовых данных.
[Типы токенов](https://dev.wildberries.ru/news/150).

Бесплатность нельзя выводить из слова «официальный». WB объявлял бесплатность
для продавцов/on-premise и Pay-as-you-go для облачных сервисов из Каталога,
с переходом после декабря 2025. Для SaaS/feed нужны условия конкретного
сервиса; никаких платных опций здесь не подключали.
[Официальное сообщение о платном доступе](https://dev.wildberries.ru/news/151).

Это техническая оценка границ доступа, не юридическое заключение. Права на
перепубликацию фотографий/данных и коммерческое использование проверяются
отдельно. Не предлагаются CAPTCHA bypass, чужие cookies, ротация IP,
маскировка fingerprint или многократные запросы после отказа.

## Минимальный контракт будущего источника

Новый адаптер сначала работает только в SHADOW. Для цены сохранять nmId,
источник, фактический `observedAt`, RUB, вариант/размер, регион, условия оплаты,
ценовой basis/число предметов, срок годности и явное наличие. Неизвестные
условия остаются unknown; seller-price отделяется от проверенной retail-price.
Скидка по зачёркнутой цене сама по себе не свидетельствует о выгоде.

Один serial worker, bounded batch, `Retry-After`/backoff, idempotent записи,
постоянный cursor и точечные индексированные чтения. 401/403 прекращают этот
источник до исправления разрешённого доступа; 429 не вызывает минутные retries.
Сначала доказать реальные свежие карточки и отсутствие дублей в isolated
SHADOW, затем отдельно согласовать подключение. Production не ждать enrichment.

## Дополнительный локальный набор для честного теста вкуса

В собственном `state.json → recent` есть 384 исторических товара с точными
CDN URL. После исключения **всех** уже оценённых nmId (81 записи, 53 уникальных
nmId) и текущих 40 карточек остаются 174 потенциальных взрослых fashion SKU
по названию/историческому запросу; обычными fashion-запросами ограничивается
165 (без DIY, медицинского/рабочего и «Уход за вещами»).

Это только candidate discovery для фотопроверки: категории ещё не подтверждены
CDN-метаданными, наличие unknown, цена не новее 2026-10-03. Эти товары уже
встречались боту; «новые для personal holdout» не означает «новые товары WB».
Не обучать стиль из названий и не добавлять их в публикационную очередь.

`queue.json` содержит 100 записей, но 0 записанных photo URL. В собственном
`docs/shadow-20261011/photos/` найдено 14 неоценённых фото вне текущего набора;
они относятся к косметике/книгам/игрушкам/автообложкам/нашивкам, а не к
пригодному подтверждённому fashion holdout. Не наполнять ими подборку ради числа.

Примеры nmId для bounded проверки `state.recent`:
`827392064`, `415941058`, `1507944909`, `848758256`, `954574390`,
`1274722797`, `1105163131`, `248526944`, `1084688290`, `960470703`,
`137987617`, `898473250`, `366719451`. Использовать записанные URL, не угадывать
CDN hosts. В этом аудите фотографии/карточки по этим URL не запрашивались.

### Ограничение проверки официальных ссылок

Использованы поисковые выдержки только первичных официальных страниц WB.
Прямой `open` нескольких страниц вернул fetch/498; это ошибка чтения документа,
не результат повторного вызова retail endpoint. Индексированные сведения могут
отставать: особенно тип токена, лимиты и тариф проверить перед внедрением.
Форумные советы и сторонние reverse-engineered API не приняты как основание
для обещания поддерживаемого бесплатного источника.
