## Исправляемые ошибки

- Ошибка обновления цены больше не разрешает отправлять сохранённую цену.
  Исходные времена наблюдения и `checked_at` сохраняются; отдельно отмечаются
  время попытки, ошибка, `fallback: true` и `priceStatus: unconfirmed`.
- После HTTP403 или timeout текущая попытка публикации прекращается после
  одного запроса деталей; другие сохранённые товары не вызывают повторную
  серию запросов в том же цикле.
- Цена, размер и положительный остаток берутся из одного стабильного SKU.
  Дешёвый отсутствующий размер не подтверждается остатком другого размера.
  Неизвестный или противоречивый остаток отклоняется.
- Целые копейки преобразуются делением на 100 без округления вниз:
  `20095 → 200.95 ₽`.
- Время цены устанавливается после завершения JSON фактического ответа WB.
  Для публикации требуется свежий ответ details, а не search, metadata,
  старая проверка или сохранённый снимок.
- Публичный текст говорит «Цена из ответа WB», указывает размер/SKU и
  зависимость итоговой цены от региона и оплаты. Ответ анонимного API
  остаётся `api_observed`, `retailConfirmed: false`, условия оплаты unknown.
  Он не доказывает цену конкретного покупателя.

### Воспроизводимая подготовка

Tracked-модуль [prepare_price_integrity_only.mjs](prepare_price_integrity_only.mjs)
экспортирует `buildPriceIntegrityOnly({outDir, includeFixtureCorrections: false})`.
Он проверяет фиксированный
SHA базы, SHA256 патча, точный список трёх путей и SHA256 полученных файлов;
экспортирует main и применяет патч только внутри `.test-temp`.
Существующий непустой каталог и symlink/junction в пути отклоняются.
Удаления, сеть, deploy и изменения исходного рабочего дерева отсутствуют.
По умолчанию companion не применяется. Только явное
`includeFixtureCorrections: true` добавляет три исправления fixtures после
независимой проверки их хеша, allowlist и итоговых файлов.
Проверки builder: **3/3 PASS**, включая сохранение runtime-хешей и assertions.

```text
node miniapp/prices/prepare_price_integrity_only.mjs .test-temp/price-only-review
```

Подготовка отдельной копии для полной регрессии с companion:

```text
node miniapp/prices/prepare_price_integrity_only.mjs .test-temp/price-only-full-review --include-fixture-corrections
```

Проверенное дерево с обоими патчами:
`.test-temp/price-integrity-only/with-companion`.

Git-объект указанной базы должен присутствовать локально; CI требуется
checkout с историей (`fetch-depth: 0`) либо заранее доступный точный объект.
Экспорт и применение используют `core.autocrlf=false` только для конкретной
команды, чтобы Windows и Linux получали одинаковые LF-хеши.

## Условия будущего запуска

Проверенная база main **не является доказательством совпадения с текущим
скомпилированным production Worker версии `21b5`**. Перед запуском необходимо:

1. Установить точное соответствие развёрнутого кода и исходников, проверить
   конфигурацию и подготовить откат на фактически работающую версию.
2. Применить только данный патч к подтверждённой базе, сверить SHA256 с
   манифестом и повторить изолированные проверки.
3. Проверить эту минимальную версию в staging с отдельной D1 и тестовыми
   ответами без настоящих публикаций; измерить CPU и бюджет D1.
4. Получить явное подтверждение владельца на production-внедрение.

Интервал 30 минут, WB Search, реакции, River SHADOW и существующая админка
должны быть сохранены. Этот документ не включает массовый сбор цен,
Visual Enrichment или passive-наблюдение.
